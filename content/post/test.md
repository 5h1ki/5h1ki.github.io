### 流程图
```mermaid
graph TD
    A[开始写博客] --> B{是否有灵感?}
    B -- 是 --> C[开始撸代码]
    B -- 否 --> D[去 Bilibili 刷视频]
    C --> E[Git Push]
```

---

*   **语法要点**
    * `graph LR`：表示图片方向是从左到右，如果是`TD`则是从上到下。
    * `[]`：表示矩形框；`{}`：表示菱形框判断；`()`：表示圆角框。

### 序列图（Sequence Diagram）
非常适合展示对象交互：
```mermaid
sequenceDiagram
    Alice->>John: 搞定了，已经Push了！
```
